# トラブルシューティング

MAXAMでよくある問題と解決策をまとめています。

## 起動時の問題

### Claude Code CLIが見つからない

**エラー:**
```
Error: claude command not found
```

**原因:**
Claude Code CLI (`claude`) がインストールされていないか、PATHに含まれていません。

**解決策:**
1. Claude Code CLIをインストール
2. PATHが通っているか確認:
   ```bash
   which claude
   ```
3. シェルを再起動するか、PATHを再読み込み:
   ```bash
   source ~/.bashrc  # または ~/.zshrc
   ```

### 設定ファイルが読み込めない

**エラー:**
```
Error: failed to load config: ...
```

**原因:**
設定ファイルのYAML構文エラー、または必須フィールドの欠落。

**解決策:**
1. 設定ファイルの構文をチェック:
   ```bash
   cat .maxam/config.yaml
   ```
2. インデントが正しいか確認（スペースを使用、タブ不可）
3. 必須フィールドがあるか確認:
   ```yaml
   version: "1"
   agents:
     - name: ...
       full_name: ...
       role: ...
   ```

### Permissionエラー

**エラー:**
```
Error: permission denied
```

**原因:**
- バイナリに実行権限がない
- ログディレクトリへの書き込み権限がない

**解決策:**
```bash
# バイナリに実行権限を付与
chmod +x /path/to/maxam

# ログディレクトリの権限を確認
ls -la ~/.maxam/
```

## エージェント関連

### エージェントが応答しない

**症状:**
- メッセージを送っても反応がない
- 「Thinking...」のまま固まる

**原因:**
- Claude Code CLIの問題
- ネットワーク接続の問題
- APIレート制限

**解決策:**
1. ネットワーク接続を確認
2. Claude Code CLIが直接動作するか確認:
   ```bash
   claude --version
   ```
3. しばらく待ってから再試行（レート制限の場合）

### メンションが認識されない

**症状:**
```
You: @yuki 実装して
Mei: はい、なんでしょう？  ← Yukiではなく Meiが応答
```

**原因:**
- エージェント名のスペルミス
- 設定ファイルにエージェントが定義されていない

**解決策:**
1. エージェント名を確認:
   ```bash
   maxam team list
   ```
2. スペルを修正して再試行

### エージェントがタイムアウトする

**エラー:**
```
context deadline exceeded
```

**原因:**
- 処理に時間がかかりすぎている
- ネットワークの問題

**解決策:**
1. タスクを小さく分割して依頼
2. ネットワーク接続を確認
3. 再試行

## レビューサイクル関連

### レビューが3ラウンド以上続く

**症状:**
- 修正しても承認されない
- 無限ループのような状態

**原因:**
- 要件が不明確
- 設計レベルの問題

**解決策:**
1. 3ラウンド後に自動エスカレーションされます
2. Meiに相談して要件を明確化
3. 必要に応じて顧客に確認

### `[SEC-CRITICAL]` で止まった

**症状:**
```
[SEC-CRITICAL] Hardcoded credentials detected
```

**原因:**
- セキュリティ上の重大な問題が検出された

**解決策:**
1. 指摘された問題を確認
2. セキュリティ問題を修正
3. Priyaに再レビューを依頼

## TUI関連

### 画面が崩れる

**症状:**
- 文字化け
- レイアウトが崩れる

**原因:**
- ターミナルサイズが小さすぎる
- ターミナルのエンコーディング問題

**解決策:**
1. ターミナルを広げる（最低80x24推奨）
2. `Ctrl+L` で画面を再描画
3. UTF-8対応のターミナルを使用

### 入力が効かない

**症状:**
- キー入力しても反応しない
- カーソルが動かない

**原因:**
- バックグラウンド処理中
- エージェントが応答待ち

**解決策:**
1. しばらく待つ（処理完了を待つ）
2. `Ctrl+C` でキャンセル
3. 再起動

### 日本語入力ができない

**症状:**
- 日本語が入力できない
- IMEが動作しない

**原因:**
- ターミナルの日本語入力設定

**解決策:**
1. ターミナルの設定で日本語入力を有効化
2. 別のターミナルエミュレータを試す（iTerm2, Alacritty等）

## 設定関連

### プロジェクト設定が反映されない

**症状:**
- `.maxam/config.yaml` を編集したのに変わらない

**原因:**
- キャッシュ
- 構文エラー

**解決策:**
1. MAXAMを再起動
2. 設定ファイルの構文を確認
3. ログを確認:
   ```bash
   ls -la ~/.maxam/logs/
   ```

### グローバル設定とプロジェクト設定の競合

**症状:**
- 期待した設定が適用されない

**原因:**
- マージルールの誤解

**解決策:**
- プロジェクト設定（`.maxam/config.yaml`）が優先されます
- `agents` 配列は完全に置換されます（マージではない）
- [設定リファレンス](configuration.md) を参照

## ログとデバッグ

### ログの場所

```
~/.maxam/logs/<project-name>/
```

各エージェントのログが保存されています。

### ログの確認

```bash
# 最新のログを確認
ls -lt ~/.maxam/logs/<project>/*.log | head -5

# ログの内容を確認
tail -100 ~/.maxam/logs/<project>/yuki_*.log
```

### 詳細なデバッグ

問題が解決しない場合は、以下の情報を収集してください：

1. MAXAMのバージョン:
   ```bash
   maxam --version
   ```

2. 設定ファイルの内容（機密情報を除く）

3. エラーメッセージの全文

4. 再現手順

## よくある質問

### Q: エージェントを追加したのに使えない

A: 設定ファイルを保存後、MAXAMを再起動してください。

### Q: 途中で処理をキャンセルしたい

A: `Ctrl+C` を押してください。確認後に終了します。

### Q: ログを削除したい

A: 以下のコマンドで削除できます：
```bash
rm -rf ~/.maxam/logs/<project>/
```

### Q: 設定をリセットしたい

A: 設定ファイルを削除して、`maxam team init` を再実行してください：
```bash
rm .maxam/config.yaml
maxam team init
```

## それでも解決しない場合

1. [GitHub Issues](https://github.com/ytnobody/MAXAM/issues) を検索
2. 新しいIssueを作成（再現手順を含める）
