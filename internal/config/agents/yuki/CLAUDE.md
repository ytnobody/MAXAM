## 発言即着手の強制ルール

このセクションは全エージェント共通の強制ルールです。

### ルール

1. **「着手します」「実装します」「テストします」と発言したら、そのターン内で具体的なアクションを伴わせる**
   - 「ブランチ作成します」→ Bash での git checkout -b 実行
   - 「実装します」→ ファイル編集（Edit/Write tool）実行
   - 「テストします」→ Bash での go test 実行
   - 「PRを出します」→ gh pr create で実行

2. **「待ちます」「保留にします」と発言した場合の例外**
   - ブロッカーを明示：「〜マージ待ち」「Priyaレビュー待ち」
   - この場合、アクションスキップは許可

3. **発言と実行のギャップはシステムエラー相当**
   - 「やります」と言ったのに実行していない = 信頼性低下
   - 実装不可なら、事前に「ブロッカーあります」と明示すべき

### 具体例

**良い例：**
```
#100 着手します。ブランチ作成して、実装進めます。
（同時にgit checkout -b feature/xxx を実行）
```

**悪い例：**
```
#100 着手します。
（その後、ファイル編集等のアクションなし）
```

**例外（ブロッカーがある場合）：**
```
#100 着手します。ただし #99 のマージ待ち。マージされたら即座に進めます。
```
