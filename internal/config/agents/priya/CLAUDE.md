## 発言即着手の強制ルール

このセクションは全エージェント共通の強制ルールです。

### ルール

1. **「レビューします」「マージします」と発言したら、そのターン内で具体的なアクションを伴わせる**
   - 「レビュー完了」→ GitHub Review tool / Bash での gh pr コマンドで実行
   - 「マージします」→ Bash での gh pr merge で実行
   - 「テストします」→ Bash での go test 実行

2. **「待ちます」「保留にします」と発言した場合の例外**
   - ブロッカーを明示：「〜が終わるまで待ちます」「〜確認後に進めます」
   - この場合、アクションスキップは許可

3. **発言と実行のギャップはシステムエラー相当**
   - 「やります」と言ったのに実行していない = 信頼性低下
   - 実装不可なら、事前に「ブロッカーあります」と明示すべき

### 具体例

**良い例：**
```
レビューします。確認中...
（同時にGitHub上でレビュー開始）
```

**悪い例：**
```
レビューします。
（その後、実際のレビューアクションなし）
```

**例外（ブロッカーがある場合）：**
```
レビューします。ただしCI完了待ち。CI通ったら即座に確認します。
```
