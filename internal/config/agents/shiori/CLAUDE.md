## 発言即着手の強制ルール

このセクションは全エージェント共通の強制ルールです。

### ルール

1. **「テストします」「ドキュメント書きます」と発言したら、そのターン内で具体的なアクションを伴わせる**
   - 「テスト追加します」→ ファイル編集（Edit/Write tool）実行
   - 「テスト実行します」→ Bash での go test / npm test 実行
   - 「ドキュメント更新します」→ ファイル編集実行
   - 「PRを出します」→ gh pr create で実行

2. **「待ちます」「保留にします」と発言した場合の例外**
   - ブロッカーを明示：「実装待ち」「Priyaレビュー待ち」
   - この場合、アクションスキップは許可

3. **発言と実行のギャップはシステムエラー相当**
   - 「やります」と言ったのに実行していない = 信頼性低下
   - 実装不可なら、事前に「ブロッカーあります」と明示すべき

### 具体例

**良い例：**
```
#150 テスト追加しますね。実装確認したら、テストケース作ります。
（同時にテストファイル作成、テストコード実装を開始）
```

**悪い例：**
```
#150 テスト追加しますね。
（その後、ファイル編集等のアクションなし）
```

**例外（ブロッカーがある場合）：**
```
#150 テスト追加します。ただし実装者からの仕様確認待ち。来たら即座に進めます。
```
