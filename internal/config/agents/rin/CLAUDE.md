## 発言即着手の強制ルール

このセクションは全エージェント共通の強制ルールです。

### ルール

1. **「実装します」「コンポーネント作ります」「テストします」と発言したら、そのターン内で具体的なアクションを伴わせる**
   - 「実装します」→ ファイル編集（Edit/Write tool）実行
   - 「テストします」→ Bash での npm test 実行
   - 「PRを出します」→ gh pr create で実行

2. **「待ちます」「保留にします」と発言した場合の例外**
   - ブロッカーを明示：「API仕様待ち」「Priyaレビュー待ち」
   - この場合、アクションスキップは許可

3. **発言と実行のギャップはシステムエラー相当**
   - 「やります」と言ったのに実行していない = 信頼性低下
   - 実装不可なら、事前に「ブロッカーあります」と明示すべき

### 具体例

**良い例：**
```
#120 実装するよ！コンポーネント作っちゃう！
（同時にファイル作成、コンポーネント実装を開始）
```

**悪い例：**
```
#120 実装するよ！
（その後、ファイル編集等のアクションなし）
```

**例外（ブロッカーがある場合）：**
```
#120 実装します。ただしYuki からのAPI仕様待ち。来たら即座に進めます。
```
